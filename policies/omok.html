오목 개인정보 처리방침

시행일: 2026년 11월 24일

오목의 AI·로컬 대전은 계정 없이 이용할 수 있습니다. 온라인 탭에 진입하면 Firebase 익명 인증으로 계정을 자동 생성하며, 계정 식별자와 전적 및 선택한 스킨을 서버에 저장합니다. 기기 이전 시에는 일회용 코드로 데이터를 새 기기로 옮깁니다.

1. 수집하는 정보

오목은 기본적으로 다음 정보는 수집하지 않습니다.

  • 게임 가입 정보로서의 이름, 이메일, 전화번호
  • GPS 좌표 등 정밀 위치 정보. 다만 분석 서비스는 IP 주소에서 대략적인 지역을 산출할 수 있습니다.
  • 결제 정보
  • 연락처나 주소록 정보

다만, 앱의 안정성 및 사용자 경험 개선을 위해 Firebase Analytics, Firebase Crashlytics, PostHog와 같은 분석 도구를 사용할 수 있으며, 앱 설치·분석 식별자, 앱 실행·화면·버튼 이용·대국 결과 등의 사용 통계, 오류·ANR 로그, 기기 정보, 앱 버전, OS 버전, 언어 정보 등이 수집될 수 있습니다. 이러한 식별자는 이름을 직접 포함하지 않더라도 특정 앱 설치나 계정과 연결될 수 있어 완전히 익명인 정보로 취급하지 않습니다. Firebase 인증은 보안 및 남용 방지를 위해 IP 주소와 사용자 에이전트도 처리합니다.

2. 수집 목적

수집된 정보는 다음 목적에만 사용됩니다.

  • 앱 기능의 안정성 및 오류 수정
  • 사용자 경험 개선 및 새 기능 검증
  • 서비스 사용 통계 분석
  • 앱 설정, 개발자의 다른 앱 추천 및 추천 화면의 이용 효과 측정
  • 온라인 대전, 계정 식별 및 일회용 기기 이전 처리
  • 대국 참가자 확인, 탈주·기권·시간 제한 처리 및 승패의 중복 정산 방지

3. 기기 내 처리

AI·로컬 대전의 진행 상태, 전적 및 스킨 선택은 기기에 저장됩니다. 온라인 대전에서는 계정 식별자, 참가자·착수·선택한 스킨·국가 표시·접속 확인 시각·승패와 정해진 빠른 대화 문구의 종류가 Firebase Realtime Database로 전달됩니다. 국가는 기기 지역 설정이나 사용자 선택으로 표시하며 GPS 위치로 정하지 않습니다. 온라인 계정은 기기 간 이전을 지원합니다. 온라인 계정 생성 및 이전 시 전적과 선택한 스킨의 사본을 서버에 저장합니다. 이전 코드가 발급되면 기존 기기의 전적과 선택한 스킨은 초기화됩니다.

근처 대전은 주변 연결을 위해 블루투스·Wi-Fi 권한을 사용합니다. 구형 Android에서는 기기 검색을 위해 위치 권한이 필요할 수 있지만, GPS 좌표를 게임 서버로 전송하지 않습니다.

4. 제3자 서비스

오목은 운영을 위해 Firebase, PostHog 등의 제3자 서비스를 사용할 수 있습니다. 해당 서비스는 분석, 오류 보고, 원격 설정, 익명 인증 및 온라인 데이터 저장 기능을 제공하며, 각 서비스는 별도의 개인정보 처리방침을 적용합니다.

  • Firebase 개인정보 보호
  • PostHog 개인정보 처리방침

5. 원격 설정

필요한 경우 Firebase Remote Config를 통해 앱 설정, 안내 메시지, 기능 플래그를 배포할 수 있습니다. 이 과정에서 앱 설치 식별 정보, 앱 버전, OS 정보, 언어 정보가 활용될 수 있습니다.

6. 보관 및 삭제

온라인 인증 계정, 전적·선택 스킨의 서버 사본, 이전 상태, 대국 기록 및 승패 정산 기록은 온라인 기능과 기기 이전을 제공하는 동안 보관하며, 계정 삭제 시 관련 데이터를 삭제합니다. 서버에는 이전 코드의 검증용 해시를 보관하고, 코드 원문은 발급 기기에 사용 전까지 저장합니다. 사용한 코드의 검증 정보는 이전 완료 시 제거합니다. 앱 삭제만으로 서버 계정이나 데이터가 삭제되지는 않습니다.

최신 앱의 설정 → 계정·데이터 삭제에서 삭제를 시작할 수 있습니다. 전적·스킨 사본, 사용하지 않은 이전 코드, 본인이 참가한 대국 데이터와 온라인 승패 기록을 정리한 뒤 Firebase 익명 인증 계정을 삭제하며, 이 기기의 전적·선택 스킨·기보·퍼즐 진행도도 초기화합니다. 진행 중인 대국은 기권으로 처리하고 상대방의 정산된 승패는 보존합니다. 이미 다른 기기로 소유권을 이전한 계정은 여기에서 지우지 않으며 해당 기기에서 삭제해야 합니다.

인터넷 연결이 필요한 삭제 작업이 실패하면 삭제를 완료했다고 표시하지 않습니다. 재시도를 위해 로그인 정보와 삭제 진행 상태를 기기에 남깁니다. 서버 정리가 끝나기 전에 인증 계정을 먼저 버리지 않으며, 앱을 다시 열거나 다시 시도하면 이어서 처리합니다.

앱을 삭제했거나 앱에 접근할 수 없는 경우의 계정·데이터 삭제 요청도 제공합니다. 문의를 통한 요청은 본인 확인 후 처리합니다. 분석·진단 서비스에 별도로 보관된 데이터에 대한 삭제 요청도 이 경로로 접수할 수 있으며, 해당 서비스의 식별·삭제 절차에 따라 처리합니다. 개인과 연결할 수 없도록 집계된 통계는 개별 기록과 분리하여 보관할 수 있습니다.

Developer sangcomz provides the application Choose it (골라줘 - kr.co.sangcomz.ppobaju). The Application does not require account registration or collect personal identity, payment, or location data. User inputs and history are processed strictly on the local device, and anonymous technical diagnostics may be used for service stability and analytics.

1. Information Collected

By default, Choose it does not collect personally identifiable information:

  • Name, email address, phone number, or personal identifiers
  • Precise location information
  • Payment or financial account information
  • Contact list or address book data

To ensure app reliability, the Application may use Firebase Analytics, Firebase Crashlytics, and PostHog to collect anonymous telemetry including crash logs, device model, OS version, app version, and language.

2. Purpose of Collection

Collected diagnostic data is used exclusively for:

  • App stability, debugging, and crash fixing
  • User experience improvement and feature validation
  • Aggregated usage analytics
  • Remote configuration and house-app recommendations

3. Device-Side Processing

All selection items and history created by the user are stored strictly on the local device storage. This data is never sent to external servers and is permanently deleted when the app is uninstalled.

4. Third-Party Services

The Application integrates the following third-party diagnostic and configuration SDKs:

  • Google Firebase Privacy Policy
  • PostHog Privacy Policy

5. Remote Configuration

Firebase Remote Config delivers dynamic app settings, feature flags, and internal recommendation banners using anonymous device identifiers and locale parameters.

6. Data Retention and Deletion

Since the Application does not maintain user accounts or personal profiles, no personal data is stored on remote servers.

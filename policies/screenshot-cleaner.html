Swidy 개인정보 처리방침

시행일: 2026년 11월 15일 · 패키지: xyz.sangcomz.cleaner

정석원(Sangcomz)이 제공하는 Swidy는 스크린샷과 사진을 한 장씩 검토하고 정리하는 Android 앱입니다. 회원가입이나 로그인은 필요하지 않습니다.

1. 사진 접근과 기기 내 처리

Swidy는 사용자가 허용한 사진 접근 권한으로 기기의 사진 목록, 파일 크기 및 스크린샷 여부를 확인합니다. 사진을 보여 주고 보관 또는 삭제 대기 목록으로 분류하며, 정리한 사진 수와 확보한 용량을 기기에 기록합니다. 사진 파일과 사진 내용은 정리 목적으로 외부 서버에 업로드하지 않습니다.

삭제 대기 목록에 추가하는 것만으로 사진이 즉시 삭제되지는 않습니다. 최종 삭제는 지원되는 Android 버전의 시스템 확인 절차를 거쳐 수행합니다. 기기 설정에서 사진 접근 권한을 변경하거나 철회할 수 있습니다.

2. 이용 분석 정보

배포 버전은 이용 현황과 기능 개선을 위해 PostHog를 사용합니다. 앱 실행·종료, 화면 조회 등의 상호작용 정보와 분석용 식별자, 앱 버전, 기기·운영체제·언어 등의 기술 정보가 분석 서비스로 전송될 수 있습니다. 분석용 식별자가 있으므로 이 데이터를 완전히 익명인 정보로 간주하지 않습니다.

분석 서비스는 기본 지역 추정 기능이 활성화된 경우 IP 주소로 국가나 도시 수준의 대략적인 위치를 추정할 수 있습니다. Swidy는 GPS를 통한 정확한 위치를 요청하지 않습니다. 현재 앱에는 이용 분석 수집을 켜거나 끄는 별도 사용자 설정이 없습니다.

사진 내용, 연락처, 결제 정보 및 사용자 계정 정보는 이용 분석을 위해 수집하지 않습니다. 문의 이메일을 보내는 경우에는 회신을 위해 이메일 주소와 문의 내용을 처리할 수 있습니다.

3. 이용 목적과 외부 처리 서비스

이용 분석 정보는 앱 사용 현황 파악과 사용자 경험 개선을 위해 사용합니다. 현재 앱의 분석 서비스는 PostHog이며 미국 호스팅 엔드포인트로 HTTPS를 통해 전송합니다. 사진의 기기 내 처리와 이러한 이용 메타데이터의 외부 전송은 서로 다른 처리입니다.

  • PostHog 개인정보 처리방침

현재 확인된 Swidy 구성에는 Firebase Analytics, Firebase Crashlytics 또는 Firebase Remote Config가 포함되어 있지 않습니다. 서비스 구성이 변경되면 실제 처리에 맞춰 이 방침을 갱신합니다.

4. 기기 내 저장과 보안

정리 통계와 필요한 앱 상태는 기기에 저장합니다. 사진은 기기의 사진 저장소에 있으며, Swidy 앱 데이터를 지우거나 앱을 제거하는 것과 사진 파일을 삭제하는 것은 별개입니다. 전송되는 분석 정보에는 HTTPS를 사용합니다.

5. 보관 및 삭제

앱의 로컬 상태는 Android의 앱 데이터 삭제 기능으로 초기화할 수 있습니다. 이는 갤러리 사진 자체를 삭제하거나, 이미 분석 서비스에 전송된 정보를 자동으로 삭제하는 기능은 아닙니다. 분석 데이터는 분석 프로젝트의 보관 설정에 따라 유지됩니다. 90일 이내 자동 삭제를 보장하지 않습니다.

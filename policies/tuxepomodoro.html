Tuxepomodoro 개인정보 처리방침

시행일: 2026년 8월 30일

Tuxepomodoro는 회원가입, 계정 생성, 결제 정보, 위치 정보 수집을 하지 않습니다. 앱은 사용자가 입력한 텍스트·이미지·설정값을 기기 안에서 처리하며, 서비스 개선과 오류 분석을 위해 익명화된 정보를 선택적으로 사용할 수 있습니다.

1. 수집하는 정보

Tuxepomodoro는 기본적으로 다음 정보는 수집하지 않습니다.

  • 이름, 이메일, 전화번호 등 개인식별정보
  • 사용자 위치 정보
  • 결제 정보 및 계정 정보
  • 연락처나 주소록 정보

다만, 앱의 안정성 및 사용자 경험 개선을 위해 Firebase Analytics, Firebase Crashlytics, PostHog와 같은 분석 도구를 사용할 수 있으며, 익명화된 사용 통계, 앱 실행 정보, 오류 로그, 기기 정보, 앱 버전, OS 버전, 언어 정보 등이 수집될 수 있습니다.

2. 수집 목적

수집된 정보는 다음 목적에만 사용됩니다.

  • 앱 기능의 안정성 및 오류 수정
  • 사용자 경험 개선 및 새 기능 검증
  • 서비스 사용 통계 분석
  • 앱 설정 및 추천 콘텐츠 제공

3. 기기 내 처리

사용자가 입력한 텍스트, 이미지, 스캔 결과, 설정값, 작업 기록 등은 기기 내부에서 처리되며 필요 시 로컬에 저장될 수 있습니다. 이 정보는 서버로 자동 전송되지 않으며, 사용자가 직접 삭제하거나 앱 재설치 시 초기화할 수 있습니다.

4. 제3자 서비스

Tuxepomodoro는 운영을 위해 Firebase, PostHog 등의 제3자 서비스를 사용할 수 있습니다. 해당 서비스는 분석, 오류 보고, 원격 설정과 같은 기능을 제공하며, 각 서비스는 별도의 개인정보 처리방침을 적용합니다.

  • Firebase 개인정보 보호
  • PostHog 개인정보 처리방침

5. 원격 설정

필요한 경우 Firebase Remote Config를 통해 앱 설정, 안내 메시지, 기능 플래그를 배포할 수 있습니다. 이 과정에서 익명화된 기기 식별 정보, 앱 버전, OS 정보, 언어 정보가 활용될 수 있습니다.

6. 보관 및 삭제

앱은 계정 기반 서비스를 제공하지 않으므로 사용자의 계정 정보, 결제 정보, 개인 연락처를 별도로 보관하지 않습니다. 로그와 분석 데이터는 서비스 개선 목적으로 필요한 범위에서 보관되며, 필요 시 정리할 수 있습니다.
